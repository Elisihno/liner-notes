# Liner Notes

A phone-friendly lyrics app: write lyrics, add line annotations, build songs, albums and artist pages, track streams and listeners, and find rhymes.

Everything is saved in your browser on your device. Use **Backup → Download backup** now and then to keep a copy.

Plain HTML and JavaScript with no build step. Open `index.html`, or turn on GitHub Pages (Settings → Pages → Deploy from branch → `main` / root).
